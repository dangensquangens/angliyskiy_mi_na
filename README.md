# Миролюбова Анастасия

С [главной](./) можно перейти к [фонетике](phonetics.html), [грамматике](grammar.html), [словарю](dictionary.html) и [домашним заданиям](homework.html). Старые ссылки на варианты открывают те же упражнения в разделе фонетики.

## Фонетика

Тренажёр чтения и фонемной транскрипции для начинающих. Два упражнения работают в обе стороны. В первом нужно записать IPA по слову, во втором — написать слово по транскрипции. По умолчанию в каждом упражнении 10 заданий. Можно выбрать от 1 до 15 и отфильтровать слова по A1 или A2.

- Для работы на сайте используйте экранные клавиши IPA и кнопку проверки под каждым упражнением. Транскрипцию можно вводить без косых черт.
- Для работы в тетради распечатайте оба задания с пустыми строками.
- Нажмите «Скачать ответы в PDF», чтобы сохранить оба задания вместе с введёнными ответами. Файл создаётся в браузере.

## Грамматика

В `data/grammar/catalog.json` перечислены категории, темы и число заданий. Адрес категории — `grammar.html?category=<id>`. Добавьте `#<id-темы>`, чтобы открыть карточку нужного времени. Новую тему или категорию добавляйте в тот же файл. У каждой категории свой идентификатор, а идентификаторы тем уникальны во всём каталоге.

[Тренажёр](grammar-practice.html) загружает задания по выбранным темам, до десяти на странице. В тренировке можно проверить ответы на текущей странице. В контрольной для самопроверки разбор открывается после завершения. В режиме просмотра решений ответы видны сразу.

При проверке регистр и лишние пробелы не влияют на результат. Допустимы варианты из ключа и отрицательные сокращения из `grammar-check.js`. В заданиях с несколькими пропусками тренажёр проверяет ответы вместе. Если ответ на задание с отметкой `review` отличается от ключа, появляется статус «Нужно сверить».

Браузер хранит черновики и результаты. У каждой попытки свой идентификатор и версия формата записи. Каталог показывает последний результат по теме. В истории можно открыть результат и повторить ошибки. Если хранилище отключено, продолжить тренировку можно, пока страница открыта.

На каждую тему приходится один файл `data/grammar/<id-темы>.json` с полями `version`, `topic` и массивом `exercises`. Схема в рабочей папке — `schemas/grammar-topic.schema.json`. При импорте скрипт сверяет тему заданий с темой файла, проверяет идентификаторы на повторы и считает записи для каталога.

- При повторном импорте у задания остаётся прежний `id`. В `prompt` лежит исходная формулировка, в `source` — идентификатор набора, а в `sourceAnswer` — исходное решение, если книга даёт его отдельно.
- При `answerMode: "gaps"` каждый элемент `answers` задаёт одну допустимую комбинацию. В ней ровно по одному ответу на каждый пропуск, в исходном порядке.
- При `answerMode: "sentence"` каждый элемент `answers` содержит одну допустимую фразу. Альтернативы добавляют после сверки.
- Метка `review` указывает, где стоит сверить возможные варианты. `translation-alternatives` относится к переводу, `word-order-alternatives` — к порядку слов. В `answers` хранится решение из книги.
- `explanation` и `difficulty` необязательны. Сложность берётся из источника или редакторской разметки.

Для локального просмотра запустите статический HTTP-сервер из `site/`.

Запустите импорт из корня рабочей папки. Нужен Python с `openpyxl`. С ключом `--check` скрипт только сверяет импорт с книгами.

```powershell
python -B scripts/import_grammar.py --source-dir "$env:USERPROFILE\Downloads"
python -B scripts/import_grammar.py --source-dir "$env:USERPROFILE\Downloads" --check
```

Скрипт читает шесть указанных в нём книг. Сводка по книгам, листам и строкам лежит в `reports/grammar-import.json`, за пределами `site/`. Если в исходных данных есть ошибки, скрипт оставляет прежние наборы и счётчики.

## Словарь

Слова и выражения A1–A2 из [Oxford 3000 по уровням CEFR](https://www.oxfordlearnersdictionaries.com/external/pdf/wordlists/oxford-3000-5000/The_Oxford_3000_by_CEFR_level.pdf) доступны сразу. В 39 группах всего 1 693 разных написания с учётом пересечений уровней. Генератор по возможности чередует группы и исключает повторы в одном варианте.

Большинство британских транскрипций получено из [Britfone](https://github.com/JoseLlarena/Britfone). В нескольких случаях варианты дополнены по отдельным статьям Oxford. В Britfone знак ударения стоит перед гласной. При проверке принимается и его расположение перед началом ударного слога. В задании с совпадающей транскрипцией возможны несколько написаний, если рядом отсутствует подсказка по значению.

## Методика

- В [Cambridge Dictionary](https://dictionary.cambridge.org/help/phonetics.html) можно послушать примеры для символов IPA, в том числе британские /ɪ/ и /iː/.
- [University of Florida Literacy Institute](https://ufli.education.ufl.edu/resources/teaching-resources/instructional-activities/) связывает практику чтения и письма с уже пройденными соответствиями между буквами и звуками. Здесь один и тот же набор правил отрабатывается в обоих направлениях.
- [Florida State University, Florida Center for Reading Research](https://fcrr.org/student-center-activities/teacher-resource-guide) предлагает подбирать задания по тому, какие буквенные сочетания ученик уже освоил. Группировка показывает репетитору, какие сочетания покрывает набор.

## Публикация

Публикуйте содержимое `site/` в корне ветки `main`. В GitHub Pages выберите **Settings → Pages → Deploy from a branch → main → / (root)**. Сайт работает без сборки. Домашние задания обращаются к внешнему API.
