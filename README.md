# Миролюбова Анастасия

На [главной странице](./) собраны ссылки на [фонетику](phonetics.html), [грамматику](grammar.html), [словарь](dictionary.html) и [домашние задания](homework.html). Прежние ссылки на варианты со старой главной открывают тот же вариант в разделе фонетики.

## Фонетика

Тренажёр чтения и фонемной транскрипции для начинающих. Два упражнения работают в обе стороны. В первом нужно записать IPA по слову, во втором — написать слово по транскрипции. По умолчанию в каждом упражнении 10 заданий. Можно выбрать от 1 до 15 и отфильтровать слова по A1 или A2.

- Для работы на сайте используйте экранные клавиши IPA и кнопку проверки под каждым упражнением. Транскрипцию можно вводить без косых черт.
- Для работы в тетради распечатайте оба задания с пустыми строками.
- Нажмите «Скачать ответы в PDF», чтобы сохранить оба задания вместе с введёнными ответами. Файл создаётся в браузере.

## Грамматика

Каталог загружает `data/grammar/catalog.json` с категориями, темами и количеством доступных заданий. Категорию открывает `grammar.html?category=<id>`. Ссылка с фрагментом `#<id-темы>` ведёт прямо к карточке времени. Чтобы добавить категорию или тему, достаточно добавить запись в каталог. Идентификаторы категорий уникальны среди категорий, идентификаторы тем уникальны во всём каталоге.

[Тренажёр](grammar-practice.html) загружает только выбранные темы и показывает до десяти заданий на странице. В тренировке можно проверить текущую страницу. Контрольная предназначена для самопроверки и показывает результаты после завершения. В режиме просмотра решений ответы сразу видны рядом с заданиями.

Проверка учитывает пробелы и регистр, поддерживает явно заданные альтернативы и перечисленные в `grammar-check.js` отрицательные сокращения. Для нескольких пропусков сверяется полная комбинация. Если ответ на задание с отметкой `review` отличается от ключа, тренажёр показывает статус «Нужно сверить».

Черновики и история хранятся в браузере, в отдельных записях с версией и идентификатором попытки. Последнюю завершённую попытку по теме можно увидеть в каталоге. В истории доступны результаты и повтор ошибок. При отключённом хранилище тренировка работает в текущей странице.

Для задач используется один JSON на тему, `data/grammar/<id-темы>.json`. Его схема хранится в рабочей папке в `schemas/grammar-topic.schema.json`. Файл содержит `version`, `topic` и массив `exercises`. Импорт сверяет тему каждой записи с темой файла, уникальность идентификаторов между файлами и соответствие счётчика числу опубликованных записей.

- `id` сохраняется при повторном импорте той же записи. `prompt` хранит исходную формулировку, `source` идентифицирует исходный набор, `sourceAnswer` хранит исходное решение, когда оно дано отдельным текстом.
- `answerMode: "gaps"` означает заполнение пропусков. Каждый элемент `answers` содержит один допустимый полный набор ответов в порядке пропусков. Длина наборов должна совпадать с числом пропусков.
- `answerMode: "sentence"` означает ответ целым предложением. Каждый элемент `answers` содержит одну допустимую фразу. Допустимые альтернативы добавляются после проверки.
- `review` отмечает задания, для которых стоит проверить допустимые варианты. `translation-alternatives` относится к переводу, `word-order-alternatives` — к порядку слов. В `answers` для них хранится решение из книги.
- `explanation` и `difficulty` необязательны. Сложность берётся из источника или редакторской разметки.

Каталог подаётся по HTTP вместе с сайтом. Для просмотра с диска можно запустить локальный статический сервер из `site/`.

Из корня рабочей папки запустите импорт шести книг с помощью Python с установленным `openpyxl`. Параметр `--check` сверяет готовые файлы с источниками без записи.

```powershell
python -B scripts/import_grammar.py --source-dir "$env:USERPROFILE\Downloads"
python -B scripts/import_grammar.py --source-dir "$env:USERPROFILE\Downloads" --check
```

Импорт читает ровно те книги, которые указаны в скрипте. Диагностика по книгам, листам и строкам записывается в `reports/grammar-import.json` за пределами `site/`. При ошибках исходных данных наборы и счётчики не перезаписываются.

## Словарь

Слова и выражения A1–A2 из [Oxford 3000 по уровням CEFR](https://www.oxfordlearnersdictionaries.com/external/pdf/wordlists/oxford-3000-5000/The_Oxford_3000_by_CEFR_level.pdf) доступны сразу. В 39 группах всего 1 693 разных написания с учётом пересечений уровней. Генератор по возможности чередует группы и исключает повторы в одном варианте.

Большинство британских транскрипций получено из [Britfone](https://github.com/JoseLlarena/Britfone). В нескольких случаях варианты дополнены по отдельным статьям Oxford. В Britfone знак ударения стоит перед гласной. При проверке принимается и его расположение перед началом ударного слога. В задании с совпадающей транскрипцией возможны несколько написаний, если рядом отсутствует подсказка по значению.

## Методика

- В [Cambridge Dictionary](https://dictionary.cambridge.org/help/phonetics.html) можно послушать примеры для символов IPA, в том числе британские /ɪ/ и /iː/.
- [University of Florida Literacy Institute](https://ufli.education.ufl.edu/resources/teaching-resources/instructional-activities/) связывает практику чтения и письма с уже пройденными соответствиями между буквами и звуками. Здесь один и тот же набор правил отрабатывается в обоих направлениях.
- [Florida State University, Florida Center for Reading Research](https://fcrr.org/student-center-activities/teacher-resource-guide) предлагает подбирать задания по тому, какие буквенные сочетания ученик уже освоил. Группировка показывает репетитору, какие сочетания покрывает набор.

## Публикация

Содержимое рабочей папки `site/` публикуется в корне ветки `main`. В GitHub Pages выберите **Settings → Pages → Deploy from a branch → main → / (root)**. Сборка фронтенда не требуется. Домашние задания используют внешний API.
