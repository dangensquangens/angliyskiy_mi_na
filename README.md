# Миролюбова Анастасия

Тренажёр чтения и фонемной транскрипции для начинающих. Два упражнения работают в обе стороны. В первом нужно записать IPA по слову, во втором — написать слово по транскрипции. По умолчанию в каждом упражнении 10 заданий. Можно выбрать от 1 до 15 и отфильтровать слова по A1 или A2.

- Для работы на сайте используйте экранные клавиши IPA и кнопку проверки под каждым упражнением. Транскрипцию можно вводить без косых черт.
- Для работы в тетради распечатайте оба задания с пустыми строками.
- Нажмите «Скачать ответы в PDF», чтобы сохранить оба задания вместе с введёнными ответами. Файл создаётся в браузере.

## Словарь

Слова и выражения A1–A2 из [Oxford 3000 по уровням CEFR](https://www.oxfordlearnersdictionaries.com/external/pdf/wordlists/oxford-3000-5000/The_Oxford_3000_by_CEFR_level.pdf) доступны сразу. В 39 группах всего 1 693 разных написания с учётом пересечений уровней. Генератор по возможности чередует группы и исключает повторы в одном варианте.

Большинство британских транскрипций получено из [Britfone](https://github.com/JoseLlarena/Britfone). В нескольких случаях варианты дополнены по отдельным статьям Oxford. В Britfone знак ударения стоит перед гласной. При проверке принимается и его расположение перед началом ударного слога. В задании с совпадающей транскрипцией возможны несколько написаний, если рядом отсутствует подсказка по значению.

## Методика

- [Cambridge English](https://www.cambridgeenglish.org/learning-english/activities-for-learners/a2p056-sit-or-seat) даёт короткие упражнения на различение близких гласных для A1–A2. В подборке представлены, в частности, короткое /ɪ/ и долгое /iː/.
- [University of Florida Literacy Institute](https://ufli.education.ufl.edu/resources/teaching-resources/instructional-activities/) связывает практику чтения и письма с уже пройденными соответствиями между буквами и звуками. Здесь один и тот же набор правил отрабатывается в обоих направлениях.
- [Florida State University, Florida Center for Reading Research](https://fcrr.org/student-center-activities/teacher-resource-guide) предлагает подбирать задания по тому, какие буквенные сочетания ученик уже освоил. Группировка показывает репетитору, какие сочетания покрывает набор.
